# Use Case — Фитнес-орталықты басқару ақпараттық жүйесі

## 1. Жүйе актерлері

Жүйенің негізгі актерлері:

- Клиент;
- Әкімші;
- Жаттықтырушы;
- Төлем жүйесі.

## 2. Негізгі Use Case

Негізгі Use Case:

**Абонементті сатып алу**

Бұл процесс клиенттің фитнес-орталықтағы қажетті абонементті таңдап, төлем жасап, абонементті жүйеде тіркеуін қамтамасыз етеді.

## 3. Use Case UC-01 — Жүйеге кіру

**Актер:** Клиент, Әкімші, Жаттықтырушы

**Мақсаты:** Пайдаланушының жүйеге авторизациядан өтуі.

### Негізгі сценарий

1. Пайдаланушы жүйенің кіру бетіне өтеді.
2. Логинін енгізеді.
3. Құпиясөзін енгізеді.
4. Жүйе енгізілген мәліметтерді тексереді.
5. Мәліметтер дұрыс болса, пайдаланушының жеке кабинеті ашылады.

### Балама сценарий

Егер логин немесе құпиясөз қате болса, жүйе қате туралы хабарлама көрсетеді.

## 4. Use Case UC-02 — Абонементті сатып алу

**Актер:** Клиент

**Қосымша актер:** Төлем жүйесі

**Мақсаты:** Клиенттің қажетті абонементті таңдап, сатып алуы.

### Негізгі сценарий

1. Клиент жүйеге кіреді.
2. «Абонементтер» бөліміне өтеді.
3. Жүйе қолжетімді абонементтерді көрсетеді.
4. Клиент қажетті абонементті таңдайды.
5. Жүйе абонементтің бағасы мен мерзімін көрсетеді.
6. Клиент «Сатып алу» батырмасын басады.
7. Жүйе төлем жасауға сұраныс жібереді.
8. Клиент төлем жасайды.
9. Төлем жүйесі төлемді өңдейді.
10. Төлем жүйесі төлем нәтижесін ақпараттық жүйеге қайтарады.
11. Егер төлем сәтті болса, жүйе абонементті клиентке тіркейді.
12. Клиентке сатып алу сәтті аяқталғаны туралы хабарлама көрсетіледі.

### Балама сценарий

Егер төлем орындалмаса:

1. Жүйе төлемнің сәтсіз болғанын анықтайды.
2. Клиентке қате туралы хабарлама көрсетіледі.
3. Клиент төлемді қайта орындай алады.

## 5. Use Case UC-03 — Клиентті тіркеу

**Актер:** Әкімші

**Мақсаты:** Жаңа клиент туралы ақпаратты жүйеге енгізу.

### Негізгі сценарий

1. Әкімші жүйеге кіреді.
2. «Клиенттер» бөліміне өтеді.
3. «Клиентті тіркеу» батырмасын басады.
4. Клиенттің аты-жөнін, телефон нөмірін және басқа мәліметтерін енгізеді.
5. Жүйе енгізілген мәліметтерді тексереді.
6. Мәліметтер дұрыс болса, жаңа клиент деректер қорына сақталады.
7. Жүйе тіркеудің сәтті аяқталғаны туралы хабарлама көрсетеді.

## 6. Use Case UC-04 — Сабаққа жазылу

**Актер:** Клиент

**Мақсаты:** Клиенттің фитнес сабағына жазылуы.

### Негізгі сценарий

1. Клиент жүйеге кіреді.
2. Сабақ кестесін ашады.
3. Қажетті жаттығуды таңдайды.
4. Жүйе бос орындардың бар-жоғын тексереді.
5. Бос орын болса, клиент сабаққа жазылады.
6. Жүйе жазылуды деректер қорына сақтайды.
7. Клиентке сабаққа жазылғаны туралы хабарлама көрсетіледі.

## 7. Use Case UC-05 — Жаттығу нәтижелерін енгізу

**Актер:** Жаттықтырушы

**Мақсаты:** Клиенттің жаттығу нәтижелерін жүйеге енгізу.

### Негізгі сценарий

1. Жаттықтырушы жүйеге кіреді.
2. Клиенттер тізімін ашады.
3. Қажетті клиентті таңдайды.
4. Жаттығу нәтижелерін енгізеді.
5. Жүйе нәтижелерді деректер қорына сақтайды.
6. Жаттықтырушы нәтижелерді қайта көре алады.

## 8. Use Case арасындағы негізгі байланыстар

«Абонементті сатып алу» Use Case келесі әрекеттерді қамтиды:

- Жүйеге кіру;
- Абонементтерді көру;
- Абонементті таңдау;
- Төлем жасау;
- Төлемді тексеру;
- Абонементті тіркеу.

Негізгі процесс:

**Клиент → Жүйеге кіру → Абонементті таңдау → Төлем жасау → Төлемді тексеру → Абонементті тіркеу.**
