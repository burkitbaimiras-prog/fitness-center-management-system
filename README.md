# fitness-center-management-system
Фитнес-орталықты басқару ақпараттық жүйесі
## Жоба туралы

Бұл жоба фитнес-орталықтың негізгі жұмыс процестерін автоматтандыруға арналған.

### Негізгі мүмкіндіктер

- Клиенттерді тіркеу;
- Абонементтерді басқару;
- Төлемдерді бақылау;
- Сабақ кестесін басқару;
- Жаттығу нәтижелерін сақтау;
- Есептерді қалыптастыру.

### Жүйе пайдаланушылары

- Клиент;
- Әкімші;
- Жаттықтырушы.
### UML диаграммалары

Жобада жүйенің құрылымы мен жұмыс процесін сипаттайтын үш UML диаграммасы бар:

- [Use Case диаграммасы](docs/diagrams/use-case.puml) — пайдаланушылардың жүйемен әрекеттесуін көрсетеді.
- [Sequence диаграммасы](docs/diagrams/sequence.puml) — абонемент сатып алу процесінің ретін көрсетеді.
- [Class диаграммасы](docs/diagrams/class.puml) — жүйенің негізгі кластары мен олардың байланыстарын көрсетеді.

- PlantUML — UML диаграммаларын құру.
